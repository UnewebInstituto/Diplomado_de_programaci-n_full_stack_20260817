El error cambió: ya no es un `404`, sino un **bucle de redirecciones**. La causa más probable está en esta ruta de `server.js`:

```js
app.get('/js', (req, res) => res.redirect('/js/'));
```

Por defecto, Express considera que la ruta `'/js'` también coincide con `'/js/'`. Así, al redirigir `/js` a `/js/`, la misma ruta vuelve a ejecutarse y redirige otra vez a `/js/`, una y otra vez. Eso provoca `ERR_TOO_MANY_REDIRECTS`.

**Corrige el manejador para redirigir solo cuando falta la barra final:**

```js
app.get('/js', (req, res, next) => {
  if (req.path === '/js') {
    return res.redirect(302, '/js/');
  }

  next();
});

app.use('/js', express.static(path.join(__dirname, 'public')));
```

También puedes quitar por completo el manejador y probar directamente la URL con barra final: `https://hduque-test.alwaysdata.net/js/`.
