# Gemini CLI con Node.js

Aplicación de consola en Node.js para consultar Gemini con una API key fuera del código.

## Requisitos

- Node.js instalado
- npm instalado

## Configuración de la API key

En Windows CMD:

```cmd
set GEMINI_API_KEY=TU_CLAVE_AQUI
```

## Instalación

```cmd
npm install
```

## Ejecución

```cmd
npm start
```

También puedes ejecutar directamente:

```cmd
node app.js
```

## Uso

- Escribe una pregunta en la consola.
- Escribe `salir` para terminar.
