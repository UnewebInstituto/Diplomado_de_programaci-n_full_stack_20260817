**Configuración de Express**
- `app.use(express.urlencoded({ extended: false }));` permite leer los datos enviados por formularios con codificación URL y dejarlos disponibles en `req.body`. `extended: false` usa un formato sencillo para esos datos.
- `app.use(express.static(...))` publica los archivos de la carpeta `public`, como páginas HTML, CSS o JavaScript del navegador.

**Preparación de valores CSV**
- `function campoCsv(valor) { ... }` convierte un valor en un campo válido de CSV:
  - `String(valor ?? "")` lo convierte a texto; si es `null` o `undefined`, usa una cadena vacía.
  - `.trim()` quita espacios al principio y al final.
  - `.replace(/"/g, '""')` duplica las comillas internas, como requiere el formato CSV.
  - Las comillas exteriores (`"..."`) protegen el campo, por ejemplo, si contiene comas.

**Ruta para guardar usuarios**
- `app.post("/usuarios", async (req, res) => { ... })` registra una ruta que responde a solicitudes `POST` enviadas a `/usuarios`. Es `async` porque realiza operaciones de archivos que se esperan con `await`.

- `await fs.appendFile(...)` agrega esa fila al final del archivo. `\r\n` añade un salto de línea compatible con el formato usado habitualmente en Windows.
- `res.status(201).send(...)` responde que el usuario se guardó correctamente. El estado `201` indica que se creó un recurso.

```javascript
const formularioUsuarios = document.getElementById("formUsuarios");
const mensajeResultado = document.getElementById("mensajeResultado");

formularioUsuarios.addEventListener("submit", async (evento) => {
    evento.preventDefault();
    mensajeResultado.textContent = "";

    try {
        const respuesta = await fetch(formularioUsuarios.action, {
            method: formularioUsuarios.method,
            headers: {
                "Content-Type": "application/x-www-form-urlencoded"
            },
            body: new URLSearchParams(
                new FormData(formularioUsuarios)
            ).toString()
        });

        const texto = await respuesta.text();
        mensajeResultado.textContent = texto;
    } catch (error) {
        console.error(error);
        mensajeResultado.textContent = "No se pudo conectar con el servidor.";
    }
});
```
