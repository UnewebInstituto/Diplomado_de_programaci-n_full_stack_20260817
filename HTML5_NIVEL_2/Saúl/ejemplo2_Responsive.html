Geolocation Api

La API de geolocalización permite al usuario proporcionar su ubicación a las aplicaciones web si así lo desea. Por motivos de privacidad, se le solicita al usuario permiso para compartir información sobre su ubicación.

e Las extensiones web que deseen utilizar el Geolocationobjeto deben añadir el "geolocation"permiso a su manifiesto. El sistema operativo del usuario le pedirá que autorice el acceso a la ubicación la primera vez que se solicite

Conceptos y usos

Con frecuencia, querrás recuperar la información de ubicación de un usuario en tu aplicación web, por ejemplo, para mostrar su ubicación en un mapa o para mostrar información personalizada relevante para su ubicación.

Se accede a la API de geolocalización mediante una llamada a navigator.geolocation; esto hará que el navegador del usuario le pida permiso para acceder a sus datos de ubicación.

Si acepta, el navegador utilizará la mejor funcionalidad disponible en el dispositivo para acceder a esta información (por ejemplo, el GPS).

El desarrollador ahora puede acceder a esta información de ubicación de varias maneras diferentes:

  • Geolocation.getCurrentPosition(): Recupera la ubicación actual del dispositivo.
  • Geolocation.watchPosition(): Registra una función controladora que se llamará automáticamente cada vez que cambie la posición del dispositivo, devolviendo la ubicación actualizada.
